2. __init__ І self
__init__ запускається під час створення об'єкта.

class Product:
    def __init__(self, name: str, price: float):
        self.name = name
        self.price = price

product = Product("iPhone", 30000)

print(product.name)   # iPhone
print(product.price)  # 30000

self — це поточний об'єкт.


3. АТРИБУТИ
Атрибути — дані, які зберігає об'єкт.

class Product:
    def __init__(self, name: str, category: str, price: float, stock: int):
        self.name = name
        self.category = category
        self.price = price
        self.stock = stock

product = Product("iPhone", "смартфон", 30000, 5)

product.name      # iPhone

product.stock     # 5

8. PRODUCT
Product зберігає назву, категорію, ціну та залишок.

class Product:
    def __init__(self, name: str, category: str, price: float, stock: int):
        self.name = name
        self.category = category
        self.price = price
        self.stock = stock

    def change_price(self, new_price: float) -> None:
        self.price = new_price

    def change_stock(self, new_stock: int) -> None:
        self.stock = new_stock


9. ORDER
Order зберігає товари та загальну суму.

class Order:
    def __init__(self):
        self.products: list[tuple[Product, int]] = []
        self.total_amount: float = 0.0

Товар з кількістю:
(product, quantity)

Наприклад:
(iPhone, 1)
(AirPods, 2)


10. ДОДАВАННЯ ТОВАРУ
def add_product(self, product: Product, quantity: int) -> None:
    self.products.append((product, quantity))
    self.total_amount += product.price * quantity

Використання:
order.add_product(product1, 1)
order.add_product(product2, 2)


11. ПЕРЕВІРКА СКЛАДУ
if quantity > product.stock:
    print(f"Недостатньо товару на складі: {product.name}")
    return

Приклад:
На складі: 5 iPhone
Замовили: 10

10 > 5 -> True
Товар не додається.


12. СПИСАННЯ ЗІ СКЛАДУ
product.change_stock(product.stock - quantity)

Наприклад:
stock = 5
quantity = 1

5 - 1 = 4

iPhone -> 4 шт.


13. РОЗРАХУНОК СУМИ
self.total_amount += product.price * quantity

iPhone:
30000 * 1 = 30000

AirPods:
7000 * 2 = 14000

Разом:
44000


14. calculate_total()
def calculate_total(self) -> None:
    self.total_amount = sum(
        product.price * quantity
        for product, quantity in self.products
    )

Простими словами:
кожен товар -> ціна * кількість -> скласти всі результати.


15. CUSTOMER
Customer має ім'я, email та список замовлень.

class Customer:
    def __init__(self, name: str, email: str):
        self.name = name
        self.email = email
        self.orders: list[Order] = []

    def add_order(self, order: Order) -> None:
        self.orders.append(order)

customer.add_order(order)

18. ЧИТАННЯ TXT
Файл products.txt:

iPhone;смартфон;30000;5
AirPods;навушники;7000;10
Lego;конструктор;1500;20
Мишка;м'яка іграшка;800;15

Код:

with open("products.txt", "r", encoding="utf-8") as file:
    for line in file:
        data = line.strip().split(";")

        name = data[0]
        category = data[1]
        price = float(data[2])
        stock = int(data[3])

        product = Product(name, category, price, stock)
        products.append(product)


19. strip() І split()
Було:
"iPhone;смартфон;30000;5\n"

strip() прибирає перенос рядка:
"iPhone;смартфон;30000;5"

split(";") розділяє:
["iPhone", "смартфон", "30000", "5"]


20. float() І int()
"30000" -> float("30000") -> 30000.0
"5"     -> int("5")       -> 5

price = float(data[2])
stock = int(data[3])


21. ЧИТАННЯ КЛІЄНТІВ
customers.txt:

Олег;oleg@gmail.com
Иван;ivan@gmail.com
Анна;anna@gmail.com

Код:

customers = []

with open("customers.txt", "r", encoding="utf-8") as file:
    for line in file:
        data = line.strip().split(";")

        name = data[0]
        email = data[1]

        customer = Customer(name, email)
        customers.append(customer)
